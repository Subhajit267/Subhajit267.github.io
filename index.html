SPHOORTI: Realtime Speech/Text to Braille Converter

MicroPython | ESP32 | Accessibility | Low-Level I/O

ReactJS mobile app captures voice, sends via Bluetooth to ESP32 (MicroPython), controlling solenoids for real-time Braille output.

SPHOORTI is an innovative accessibility device that converts speech or text to Braille in real-time. The system consists of a ReactJS mobile application that captures voice input or accepts text, which is then transmitted via Bluetooth to an ESP32 microcontroller running MicroPython. The ESP32 controls solenoids that physically form Braille characters, enabling real-time tactile communication for visually impaired users. This project demonstrates expertise in embedded systems, IoT connectivity, and accessibility technology.
